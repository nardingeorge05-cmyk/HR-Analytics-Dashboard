# HR Analytics Dashboard | Power BI

## 1. Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee data and provide meaningful insights into workforce distribution, employee performance, demographics, turnover, and attendance.

The project aims to transform raw HR data into clear and interactive visualizations that support data-driven decision-making.

## 2. Data Cleaning & Preparation
Before building the dashboard, the dataset was prepared and cleaned to improve data quality and ensure accurate analysis.

Key activities included:
- Data Cleaning.
- Data Preparation and Transformation.
- Reviewing data consistency.
- Preparing the dataset for analysis.

## 3. Measures & KPI Development
Created measures to calculate and monitor important HR metrics and Key Performance Indicators (KPIs), supporting the dashboard's analytical functionality.

## 4. Dashboard Pages

### HR Dashboard Overview
Provides a general overview of the workforce, including total employees, active employees, gender distribution, and performance ratings.

### Workforce Insights
Analyzes workforce distribution across departments, job roles, and age groups.

### Performance Insights
Explores employee performance ratings and their distribution across departments.

### Demographic Insights
Provides insights into employee demographics, gender distribution, and workforce characteristics.

### Turnover & Attendance
Analyzes employee turnover (Attrition), years at the company, and attendance-related metrics.

### Measures
Displays the measures developed to support HR calculations and dashboard KPIs.
